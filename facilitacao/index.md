# Biblioteca de Técnicas de Facilitação e Icebreakers

> Biblioteca colaborativa da Portugal Agile Leaders Network: técnicas de facilitação, icebreakers e energizers testados nos nossos encontros. Cada entrada descreve o que é, quando usar e como correr — para qualquer membro poder replicar.

## Como contribuir

1. Facilitou ou experimentou uma técnica num encontro (ou na sua organização)? Crie um ficheiro nesta pasta: `nome-da-tecnica.md`.
2. Use o template disponível no ficheiro [`_template.md`](_template.html).
3. Edite diretamente no GitHub (✏️ ou "Add file → Create new file") e faça "Commit changes".
